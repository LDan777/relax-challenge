## 📋 项目概述

Aurora520 是一个基于脑电波（EEG）的放松挑战应用，通过实时监测用户的放松指数（RELAX Index），帮助用户进入放松状态。支持仿真模式和真实蓝牙设备两种工作模式。

### ✨ 核心功能

- 🧠 **实时脑电波处理** - 每秒接收和处理 RELAX 指数
- 📊 **动态波形图显示** - 使用 ECharts 实时展示数据变化
- 🎯 **自适应阈值计算** - 基于基线自动计算目标阈值
- 🔌 **双模式支持** - 仿真模式和真实蓝牙设备无缝切换
- 💡 **一键启动** - EXE 文件直接运行，无需配置
- ⏸️ **完整控制** - 支持暂停、结束等操作

## 🚀 快速开始

### 方式一：直接运行 EXE（推荐）

最简单的方式，无需安装任何依赖：

```bash
# 1. 双击运行 EXE 文件
Aurora520project/dist/main_app/main_app.exe

# 2. 浏览器会自动打开应用
# 如果没有自动打开，手动访问：http://localhost:5173

# 3. 选择模式并开始挑战
```

### 方式二：开发模式

需要 Python 3.8+ 和 Node.js 14+

```bash
# 1. 安装依赖
pip install -r requirements.txt
cd relax_frontend && npm install

# 2. 在三个不同的终端中启动服务
# 终端1：数据源服务
python aurora_server.py

# 终端2：算法处理服务
python relax_challenge.py

# 终端3：前端开发服务
cd relax_frontend
npm run dev

# 3. 打开浏览器访问 http://localhost:5173
```

## 📊 工作流程

### 基线采集阶段（10秒）
```
系统采集 10 秒的放松指数数据
    ↓
计算平均值作为基线
    ↓
目标阈值 = 基线 × 1.15
```

### 挑战阶段（最多120秒）
```
需要保持放松指数 ≥ 目标阈值
    ↓
连续保持 4 秒即可成功
    ↓
如果中途下跌，计时器重置
```

### 结果反馈
```
✅ 成功：显示总耗时
❌ 失败：提示重新尝试
```

## 🎮 使用指南

### 1. 选择模式
- **💡 仿真模拟挑战**：使用虚拟数据，适合测试和演示
- **🔌 连蓝牙设备**：连接真实 ESP32 设备，获取真实脑电数据

### 2. 开始挑战
- 点击"开始挑战"按钮
- 系统自动采集 10 秒基线数据
- 进入 120 秒挑战阶段

### 3. 挑战过程
- 实时显示 RELAX 指数
- 显示目标阈值参考线
- 显示倒计时

### 4. 成功条件
- 连续保持 4 秒以上达到阈值 → 成功 🎉
- 120 秒内未达到 → 失败 ❌

## 🔌 蓝牙设备连接

### 硬件要求
- ESP32 开发板
- 支持 BLE（蓝牙低功耗）
- 脑电采集模块（如 MuseS）

### 数据格式
```
蓝牙发送格式: "RELAX:0.95"
更新频率: 每秒一次
```

## 💡 仿真模式

仿真模式使用虚拟数据生成，特点：
- ✅ 无需硬件设备
- ✅ 数据波动真实（正弦波+噪声）
- ✅ 适合功能测试和演示

**数据特性**：
- 基础值：0.8
- 波动范围：0.5 ~ 1.5
- 波动方式：正弦波 + 随机噪声
- 更新频率：每秒一次
- 周期：10 秒一个完整周期

## ⚙️ 配置参数

### aurora_server.py
```python
MOCK_MODE = True              # True: 模拟模式 | False: 真实蓝牙模式
PORT = 8765                   # WebSocket 服务器端口
```

### relax_challenge.py
```python
BASELINE_DURATION = 10.0      # 基线采集时长（秒）
THRESHOLD_BOOST = 1.15        # 阈值提升系数
REQUIRED_HOLD_TIME = 4.0      # 需要保持的时长（秒）
CHALLENGE_TIMEOUT = 120.0     # 挑战超时时长（秒）
```

## 🐛 常见问题

### Q: 应用启动后浏览器没有打开
**A:** 请手动访问 `http://localhost:5173`

### Q: 网页显示空白？
**A:** 检查浏览器控制台（F12）是否有错误，确保三个服务都已启动。

### Q: 连接错误？
**A:** 确保 `relax_challenge.py` 已启动，端口 8888 未被占用。

### Q: 数据不更新？
**A:** 确保 `aurora_server.py` 已启动，检查后端日志。

### Q: 如何使用真实蓝牙？
**A:** 将 `aurora_server.py` 中 `MOCK_MODE` 改为 `False`，确保 ESP32 设备已连接。

### Q: 连接蓝牙设备失败
**A:** 
- 检查 ESP32 是否已启动
- 确保蓝牙主控程序已烧录
- 查看控制台错误信息

### Q: 波形图显示不正常
**A:**
- 刷新浏览器页面
- 检查浏览器控制台是否有错误
- 确保后端服务正常运行
