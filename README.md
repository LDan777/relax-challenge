# 🧠 Aurora520 极速放松挑战

一个基于脑电波（BCI）的实时放松挑战系统，通过监测用户的放松指数（RELAX Index）帮助用户进入放松状态。

## 🚀 快速开始

### 1. 启动三个服务（分别在三个终端中）

```bash
# 终端1：启动数据源服务
cd Aurora520project
python aurora_server.py

# 终端2：启动算法处理服务
cd Aurora520project
python relax_challenge.py

# 终端3：启动前端开发服务
cd Aurora520project/relax_frontend
npm install  # 首次运行
npm run dev
```

### 2. 打开浏览器
访问 `http://localhost:5173/`

### 3. 开始挑战
点击"开始挑战"按钮，按照提示进行操作。

---

## 📊 模拟数据说明

当 `aurora_server.py` 中 `MOCK_MODE = True` 时，系统会生成虚拟 RELAX 指数数据：

**模拟数据特性**：
- 📈 **基础值**：0.8（可调整）
- 🌊 **波动范围**：0.5 ~ 1.5
- 📊 **波动方式**：正弦波 + 随机噪声
- ⏱️ **更新频率**：每秒一次
- 🔄 **周期**：10 秒一个完整周期

**模拟数据公式**：
```
RELAX指数 = 基础值 + 正弦波(10秒周期) + 随机噪声(-0.1~0.1)
```

**预期效果**：
- 网页中会看到 RELAX 指数实时波动
- 波形图会显示平滑的曲线变化
- 基线采集时会看到 10 秒倒计时
- 10 秒后自动进入挑战阶段

**切换到真实蓝牙模式**：
编辑 `aurora_server.py`，将 `MOCK_MODE = True` 改为 `MOCK_MODE = False`

## 🔧 核心功能

| 功能 | 说明 |
|------|------|
| 📊 实时监测 | 每秒接收一次 RELAX 指数 |
| 📈 基线采集 | 自动采集 10 秒基线数据（带倒计时） |
| 🎯 阈值检测 | 基于基线计算目标阈值（基线 × 1.15） |
| ✅ 成功判定 | 连续保持 4 秒以上达到阈值即成功 |
| ⏱️ 超时控制 | 120 秒内未成功则失败 |
| ⏸️ 暂停/结束 | 支持暂停和结束挑战 |

## 📊 数据流

```
ESP32 (主控计算 RELAX)
    ↓ BLE 蓝牙 "RELAX:0.95"
aurora_server.py (Port 8765)
    ├─ 解析 RELAX 指数
    ├─ 广播给所有客户端
    ↓ WebSocket
relax_challenge.py (Port 8888)
    ├─ 接收 RELAX 指数
    ├─ 执行挑战逻辑
    ├─ 计算基线和阈值
    └─ 广播状态给前端
    ↓ WebSocket 双向
relax_frontend (Port 5173)
    ├─ 显示实时数据
    ├─ 显示挑战状态
    └─ 提供控制按钮
```

## 🎮 使用流程

1. **点击"开始挑战"**
   - 前端连接到后端
   - 发送重置命令
   - 开始采集基线

2. **基线采集阶段（10秒）**
   - 显示"正在采集10秒基线..."
   - 显示倒计时：`基线采集: 10 / 10 秒` → `基线采集: 1 / 10 秒`
   - 后端采集 RELAX 指数
   - 计算平均基线值

3. **挑战阶段（最多120秒）**
   - 显示"挑战中！请放松大脑..."
   - 实时显示 RELAX 指数
   - 显示目标阈值参考线
   - 显示倒计时

4. **成功/失败**
   - 连续保持 4 秒以上达到阈值 → 成功 🎉
   - 120 秒内未达到 → 失败 ❌
   - 点击"结束"按钮 → 失败 ❌
   - 基线采集失败 → 失败 ❌

## 📝 配置参数

编辑 `relax_challenge.py` 修改以下参数：

```python
BASELINE_DURATION = 10.0      # 基线采集时长（秒）
THRESHOLD_BOOST = 1.15        # 阈值提升系数
REQUIRED_HOLD_TIME = 4.0      # 需要保持的时长（秒）
CHALLENGE_TIMEOUT = 120.0     # 挑战超时时长（秒）
```

编辑 `aurora_server.py` 修改以下参数：

```python
MOCK_MODE = True              # True: 模拟模式 | False: 真实蓝牙模式
PORT = 8765                   # WebSocket 服务器端口
```

## 🐛 常见问题

### Q: 网页显示空白？
A: 检查浏览器控制台（F12）是否有错误，确保三个服务都已启动。

### Q: 连接错误？
A: 确保 `relax_challenge.py` 已启动，端口 8888 未被占用。

### Q: 数据不更新？
A: 确保 `aurora_server.py` 已启动，检查后端日志。

### Q: 基线采集一直在进行？
A: 这是已修复的问题，确保使用最新代码。

### Q: 网页中没有波动？
A: 检查 `aurora_server.py` 中 `MOCK_MODE` 是否为 `True`，确保模拟数据生成器已启动。

### Q: 如何使用真实蓝牙？
A: 将 `aurora_server.py` 中 `MOCK_MODE` 改为 `False`，确保 ESP32 设备已连接。
