# Aurora520 极速放松挑战 - EXE 使用说明

## 📦 项目概述

Aurora520 是一个基于脑电波（EEG）的放松挑战应用，通过实时监测用户的放松指数（RELAX Index），帮助用户进入放松状态。

**核心功能：**
- 🧠 实时脑电波数据采集与处理
- 📊 动态波形图显示
- 🎯 自适应阈值计算
- 🔌 支持真实蓝牙设备和模拟模式
- 💡 一键启动，无需配置

---

## 🚀 快速开始

### 方式一：直接运行 EXE（推荐）

1. **找到 EXE 文件**
   ```
   Aurora520project/dist/main_app/main_app.exe
   ```

2. **双击运行**
   - 应用会自动启动所有服务
   - 浏览器会自动打开应用界面
   - 如果浏览器没有自动打开，请手动访问：`http://localhost:5173`

3. **选择模式**
   - 💡 **仿真模拟挑战**：使用虚拟数据测试（推荐新手）
   - 🔌 **连蓝牙设备**：连接真实 ESP32 蓝牙设备

4. **开始挑战**
   - 点击"开始挑战"按钮
   - 系统会先采集 10 秒基线数据
   - 然后进入 120 秒挑战阶段
   - 保持放松指数高于目标阈值 4 秒即可成功

## 📊 工作流程

### 1️⃣ 基线采集阶段（10秒）
```
系统会采集 10 秒的放松指数数据
计算平均值作为基线
目标阈值 = 基线 × 1.15
```

### 2️⃣ 挑战阶段（最多120秒）
```
需要保持放松指数 ≥ 目标阈值
连续保持 4 秒即可成功
如果中途下跌，计时器重置
```

### 3️⃣ 结果反馈
```
✅ 成功：显示总耗时
❌ 失败：提示重新尝试
```

## 🎮 界面说明

### 模式选择按钮
- **💡 仿真模拟挑战**：使用虚拟数据，适合测试和演示
- **🔌 连蓝牙设备**：连接真实 ESP32 设备，获取真实脑电数据

### 控制按钮
- **开始挑战**：启动新的挑战
- **⏸️ 暂停**：暂停当前挑战
- **⏹️ 结束**：结束当前挑战

### 实时数据显示
- **当前放松指数**：实时显示的 RELAX 值
- **目标阈值**：需要达到的目标值
- **波形图**：实时显示数据变化趋势

## 🔌 蓝牙设备连接

### 硬件要求
- ESP32 开发板
- 支持 BLE（蓝牙低功耗）
- 脑电采集模块（如 MuseS）

### 连接步骤
1. 确保 ESP32 已烧录蓝牙主控程序
2. 在应用中选择"🔌 连蓝牙设备"
3. 点击"开始挑战"
4. 系统会自动扫描并连接设备

### 数据格式
```
蓝牙发送格式: "RELAX:0.95"
每秒发送一次
```

## 💡 仿真模式说明

仿真模式使用虚拟数据生成，特点：
- ✅ 无需硬件设备
- ✅ 数据波动真实（正弦波+噪声）
- ✅ 适合功能测试和演示
- ✅ 数据范围：0.5 ~ 1.5

## 🐛 常见问题

### Q1: 应用启动后浏览器没有打开
**A:** 请手动访问 `http://localhost:5173`

### Q2: 连接蓝牙设备失败
**A:** 
- 检查 ESP32 是否已启动
- 确保蓝牙主控程序已烧录
- 查看控制台错误信息

### Q3: 波形图显示不正常
**A:**
- 刷新浏览器页面
- 检查浏览器控制台是否有错误
- 确保后端服务正常运行

### Q4: 挑战无法开始
**A:**
- 确保已选择模式（仿真或蓝牙）
- 检查后端服务是否启动
- 查看浏览器控制台错误信息
